Implementation notes
--------------------
1. Keep the Hero overlays: they guarantee white text contrast against the image.
2. Mobile uses compact Header controls and a 3-column category grid; desktop expands to 7 columns.
3. The actual application uses CSS variables such as --ink, --muted, --line,
   --accent, --surface, and --background. Preserve them when porting this layout.
4. Dynamic components intentionally omitted: i18n provider, product catalog fetch,
   cart state, search behavior, menu drawer portal, product badge calculation,
   and checkout/Stripe logic.
